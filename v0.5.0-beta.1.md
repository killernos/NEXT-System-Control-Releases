# NEXT System Control v0.5.0 Beta 1

The first public beta of NEXT System Control, a PlayStation 4 homebrew
system-management and diagnostics application.

## Hardware validation

Verified on a PlayStation 4 running firmware 12.00 with GoldHEN. Revision 21
passed the reported filesystem and UI hardware checks. SSH authentication and
FTP root-directory listing were also demonstrated. Other firmware versions
and hardware configurations have not been verified for this release.

## Installation

1. Use a compatible jailbroken PS4 running firmware 12.00 with GoldHEN.
2. Download `NEXT-Stage7-Revision21.pkg`.
3. Install it through the console's package installer using your normal
   trusted local workflow.
4. Launch NEXT System Control.
5. Enable SSH or FTP only when needed and only on a trusted local network.
   Do not expose either service to the internet.

Back up important data before installing beta software. Installation and
compatibility behavior may vary by console setup.

## Beta limitations

- This is a beta, not a stable production release.
- Firmware 12.00 with GoldHEN is the only verified configuration; other
  firmware and hardware combinations are unverified.
- FTP does not provide TLS encryption. Use it only on a trusted local
  network.
- The on-console filesystem browser supports a limited set of directories.
- Root privilege transitions and unrestricted filesystem modifications are
  not enabled in the browser.
- Normal application exit behavior requires further compatibility testing.
