# NEXT System Control v0.5.0 Beta 3 — Six Themes & Debugger Diagnostic

Beta 3 includes the modern NEXT dashboard, six selectable themes, Explorer and
Developer startup modes, and the controller-accessible Tool Library. It also
contains a diagnostic change to the manual, read-only ps4debug client: the
client now targets the console's detected local IPv4. This release does not
include or load ps4debug-NG, start GoldHEN services, or grant privileges.

## Main feature: dashboard and six themes

- Rounded dashboard panels and cards, clear controller focus indicators, and
  compact system-status information.
- Six selectable themes: Matrix Green (default), Cyber Blue, Royal Purple,
  Crimson Red, Amber Gold, and Monochrome.
- Open the theme selector with Square from System Info. Choose a theme with
  the D-pad and apply it with Cross.
- The dashboard and Explorer/Developer startup selector follow the selected
  theme.
- Theme choice, favorites, recently used tools, and the active Tool Library
  category are saved between launches.

## Explorer, Developer, and Tool Library

- Choose Explorer Mode or Developer Mode at startup.
- Explorer provides read-only system information, filesystem navigation,
  monitoring, and diagnostics.
- Developer tools remain capability-gated. Selecting Developer Mode does not
  automatically elevate privileges or start network services.
- Open the Tool Library with L2. Browse categories, Favorites, and Recently
  Used with Left/Right; move through tools with Up/Down.
- Search with Triangle using the native PS4 text-entry dialog; R2 clears the
  search. Cross opens an available view, Square toggles a favorite, and Circle
  closes the library or theme selector.
- Only tools with an implemented dashboard view can be opened from the library.

## Other improvements

- Corrected startup-selector banner layering and centered dashboard
  navigation icons.
- Restored the preferred native PS4 password keyboard.
- Saved credentials use a salted PBKDF2 password verifier rather than
  plaintext; SSH reconnect behavior after cancelling password entry was
  improved.
- Corrected host-build remote-shell argument parsing and added regression
  coverage without changing the established PS4 command-validation boundary.

## Additional debugger diagnostic change

- The manual read-only debugger query targets NEXT's freshly detected
  console-local IPv4 address on TCP port 744 instead of assuming that PS4
  loopback (`127.0.0.1`) reaches the payload listener.
- The target is obtained from NEXT's network snapshot; no user-supplied
  remote address is accepted. The query runs only when explicitly requested.
- NEXT does not load or resend a payload, attach to processes, access process
  memory, modify the kernel, or grant privileges.

## PS4 diagnostic result

The maintainer tested this exact package on PS4. The screen showed the
detected local address as the target, but the connection failed with
`errno 61` (connection refused) on TCP port 744. This confirms the client
attempted the detected console address; it does **not** confirm that
ps4debug-NG started or that a debugger server is listening. Use this release
as a diagnostic result, not as a claim that debugger connectivity is fixed.
This is the observed result for the debugger probe; it does not negate the
separately tested dashboard and theme functionality.

## How to test

1. Install the package using the PS4 package installer and launch NEXT.
2. Open the read-only GoldHEN / PS4Debug diagnostic screen.
3. Confirm the displayed destination is the console's current local IPv4 on
   port 744, then press X once to run the manual query. For dashboard themes,
   open System Info and press Square.
4. Record the exact debugger status. A connection-refused result means port
   744 is not reachable; it does not identify why the server is unavailable.

NEXT does not load or resend a payload as part of this query. It does not
attach to processes, access process memory, alter the kernel, or elevate
privileges.

## Network use

TLS-encrypted; do not expose either service to the public internet.
