# NEXT System Control v0.5.0 Beta 2

Beta 2 adds a controller-driven dashboard theme selector and Tool Library, six selectable themes with saved preferences, and refinements to the Explorer/Developer startup selector and dashboard icon alignment.

## Validation

- PC simulator regression suite: 6/6 passed.
- OpenOrbis PS4 ELF and FSELF build completed; package generation succeeded.
- The user reports that this Beta 2 build works on PS4. Firmware, test-cycle count, and individual test coverage were not recorded. No broader compatibility claim is made.

## Installation

1. Review this beta's limitations and back up important data before installation.
2. Confirm the package title ID `NEXT00034` is unused on your console; the package is internally labeled as a test package.
3. Install using your normal, trusted local package-installation workflow.
4. Enable SSH or FTP only when needed and only on a trusted local network. Do not expose either service to the internet.

## Beta limitations and safety

- This is beta software, not a stable production release.
- Hardware validation is limited to the user report above; firmware and test details were not recorded, and other configurations are unverified.
- FTP traffic is not protected by TLS. Use FTP only on a trusted local network and only when needed.
- The filesystem browser supports a limited set of directories and does not enable unrestricted filesystem modification.
- Privileged operations require explicit authorization; automatic privilege elevation is not enabled.
