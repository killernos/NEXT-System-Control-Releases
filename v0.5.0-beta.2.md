# NEXT System Control v0.5.0 Beta 2

Beta 2 brings the new NEXT dashboard, Explorer and Developer startup modes,
personalization, and a controller-accessible Tool Library. It also improves
PS4 password entry, credential handling, and SSH reconnect reliability.

## Added

### Modern dashboard and six themes

- Rounded panels and cards, clear controller focus indicators, and compact
  system-status information.
- Six selectable themes: Matrix Green (default), Cyber Blue, Royal Purple,
  Crimson Red, Amber Gold, and Monochrome.
- Open the theme selector with Square from System Info. Select a theme with
  the D-pad and apply it with Cross.
- The dashboard and Explorer/Developer startup selector follow the selected
  theme.

### Explorer and Developer startup modes

- Choose Explorer Mode or Developer Mode each time the application starts.
- Explorer Mode provides read-only system information, filesystem navigation,
  monitoring, and diagnostics.
- Developer Mode exposes advanced tools through capability checks. Choosing
  this mode does not automatically elevate privileges or start network services.
- Tool availability reflects the current mode and runtime capabilities.

### Tool Library and saved preferences

- Open the Tool Library with L2 and browse tools by category.
- Favorites and Recently Used filters make it easier to return to tools.
- Search uses the native PS4 text-entry dialog.
- Theme selection, favorites, recently used tools, and the active category
  are saved between launches.
- Only tools with an implemented dashboard view can be opened from the library.

## Fixed and improved

- Corrected startup-selector banner layering and centered dashboard
  navigation icons.
- Restored the preferred native PS4 password keyboard.
- Fixed the credentials issue encountered during SSH setup; saved credentials
  use a salted PBKDF2 password verifier rather than plaintext.
- Improved SSH reconnect behavior after cancelling password entry.
- Corrected host-build remote-shell argument parsing and added regression
  coverage without changing the established PS4 command-validation boundary.

## Controller quick reference

| Action | Control |
| --- | --- |
| Open themes from System Info | Square |
| Open Tool Library | L2 |
| Change category, Favorites, or Recently Used filter | Left / Right |
| Select a tool | Up / Down |
| Open an available tool view | Cross |
| Toggle a tool favorite | Square |
| Search tools | Triangle |
| Clear search | R2 |
| Close the theme selector or Tool Library | Circle |

## Testing

- Tested on PS4 before release, with the release build confirmed working
  by the maintainer.
- PC regression suite: 6/6 passed.
- OpenOrbis PS4 ELF, FSELF, and package builds completed successfully.

## Installation

1. Download `NEXT.System.Control.v0.5.0.Beta.2.pkg` from this release's assets.
2. Transfer it to your jailbroken PS4 using your usual installation workflow
   and install it with the PS4 package installer.
3. Launch NEXT System Control.

## Network use

Enable SSH or FTP only when needed on a trusted local network. FTP is not
TLS-encrypted; do not expose either service to the public internet.
